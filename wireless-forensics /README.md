# Wireless Forensics

Wireless forensics tools are used to **capture, monitor, and analyze WiFi network traffic**. They help investigate unauthorized access, rogue access points, and attacks targeting wireless networks.

### When do we use these tools?
- When we investigate unauthorized access to a WiFi network
- When we need to capture wireless traffic for analysis
- When we are looking for rogue or suspicious access points
- When we analyze attacks targeting wireless protocols (WPA2, WPS, etc.)
