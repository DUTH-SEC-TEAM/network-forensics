# Network Forensic Analysis

Network forensic analysis tools are used for **deep investigation of network incidents**. They go beyond simple traffic capture and help reconstruct events, extract artifacts, and build a timeline of what happened during an attack or incident.

### When do we use these tools?
- When we are investigating a security incident and need to reconstruct what happened
- When we want to extract files, emails, or credentials from network traffic
- When we need to build a timeline of attacker activity
- When we combine network artifacts with host-based forensics

## Tools

| Tool | Description | Platform | File |
|------|-------------|----------|------|
| [Xplico](./xplico.md) | Reconstructs application data from pcap files (emails, HTTP, VoIP) | Linux | `xplico.md` |
| [NetworkMiner](./networkminer.md) | Extracts files, images, and credentials from pcap files | Linux / Windows | `networkminer.md` |
