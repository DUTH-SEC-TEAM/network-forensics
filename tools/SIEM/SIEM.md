# Description

SIEM (Security Information and Event Management) platforms **collect, centralize, and correlate logs and events** from multiple sources across a network. They help security teams detect threats, investigate incidents, and maintain visibility across the entire infrastructure.

### When do we use these tools?
- When we need to centralize logs from multiple devices (firewalls, servers, IDS)
- When we want to correlate events across different sources to detect an attack
- When we need dashboards and alerts for ongoing monitoring
- When we are investigating an incident and need to search across all logs
