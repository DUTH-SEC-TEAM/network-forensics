# Description

Packet capture tools allow us to **record raw network traffic** passing through an interface. The captured data is saved in `.pcap` or `.pcapng` format and can be analyzed later with traffic analysis tools.

### When do we use these tools?

- When we want to capture live traffic from a network interface
- When we need to record suspicious activity for later analysis
- When we receive a `.pcap` file and want to open/inspect it
